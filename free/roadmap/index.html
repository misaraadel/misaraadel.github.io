الخريطة دي ماشية على ترتيب roadmap.sh/frontend (ريبو developer-roadmap على GitHub، عليه أكتر من 370 ألف نجمة):

roadmap.sh/frontend

لو بتذاكر ساعتين في اليوم، الخطة دي حوالي ٤ شهور. ولو وقتك أقل، كمّل بنفس الترتيب بس على مدة أطول.

أهم حاجة: اعمل مشروع صغير في آخر كل مرحلة، حتى لو بسيط.

المرحلة ١: الأساسيات (أسبوع ١–٢)

  • إزاي الإنترنت بيشتغل: يعني إيه HTTP، والدومين، والاستضافة، والمتصفح.
  • HTML: العناوين، والفورم، والجداول، والـsemantic tags.
  • مشروع: صفحة شخصية بسيطة بـHTML بس.

المرحلة ٢: CSS (أسبوع ٣–٥)

  • الأساسيات: الألوان، والخطوط، والـbox model.
  • الترتيب: Flexbox وGrid.
  • الموبايل: Responsive وmedia queries.
  • مشروع: Landing page متجاوبة مع الموبايل.

المرحلة ٣: JavaScript (أسبوع ٦–١٠)

  • الأساسيات: المتغيرات، والـfunctions، والـarrays، والـobjects.
  • الصفحة: DOM وevents.
  • البيانات: fetch وasync/await، وتجيب بيانات من API.
  • مشروع: تطبيق طقس أو To-Do. شوف ١٠ أفكار مشاريع بـAPIs ببلاش.

المرحلة ٤: Git وGitHub (أسبوع ١١)

  • Git: الـcommit، والـbranch، والـmerge.
  • GitHub: ترفع مشاريعك، وتنشر موقعك على GitHub Pages. شوف برومبت البورتفوليو والدومين المجاني.

المرحلة ٥: الأدوات (أسبوع ١٢)

  • npm: وإزاي تنزّل packages.
  • Vite: إزاي تعمل مشروع جديد بيه.

المرحلة ٦: Framework (أسبوع ١٣–١٦)

  • اختار واحد بس وكمّل فيه: React أو Vue.
  • اتعلم فيه: الـcomponents، والـprops، والـstate، والـrouting.
  • Tailwind CSS علشان تبني أسرع.
  • مشروع: موقع كامل فيه أكتر من صفحة، وبيجيب بيانات من API.

بعد كده

  • TypeScript.
  • الاختبارات (Testing).
  • الأداء (Performance).
  • الـAI في البرمجة: roadmap.sh نفسه بقى فيه جزء عنه في خريطة الفرونت إند.
  • علّم على اللي خلّصته على roadmap.sh، علشان تشوف وصلت لفين.
