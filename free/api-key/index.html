أي مفتاح بيوصل للمتصفح باين لأي حد: يدوس F12 ← Network ← يفتح الريكويست ← المفتاح قدّامه. وبعدها يستخدمه على حسابك، وإنت اللي تدفع.

✅ اختبر موقعك دلوقتي (دقيقة واحدة)

  1. افتح موقعك ودوس F12 (أو كليك يمين ← Inspect).
  2. روح على Network واعمل الحاجة اللي بتكلّم الـAI (ابعت رسالة مثلًا).
  3. دوس على الريكويست وبص في Headers وPayload.
  4. وكمان من تاب Sources دوس Ctrl + Shift + F (أو Cmd + Option + F على الماك) وابحث عن sk- أو key.

لو لقيت المفتاح ← كمّل الصفحة دي. ولو المفتاح اتنشر قبل كده، اعمله Revoke من حسابك واعمل واحد جديد فورًا.

❌ ليه .env لوحده مش كفاية؟

أي متغيّر بيبدأ بـVITE_ أو NEXT_PUBLIC_ أو REACT_APP_ بيتحط جوه ملفات الـJavaScript اللي بتروح للمتصفح وقت الـbuild. يعني .env بيخبّيه من GitHub، مش من الزوّار.

١) المفتاح يفضل على السيرفر 🔒

الفكرة:

المتصفح  ←→  السيرفر بتاعك (المفتاح هنا بس)  ←→  الـAPI

الموقع بيكلّم رابط عندك، والرابط ده هو اللي بيكلّم الـAPI بالمفتاح.

٢) من غير باك إند كامل: Serverless Function (ببلاش) ⚡

مثال على Vercel. اعمل ملف api/chat.js في المشروع:

export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).end();

  const r = await fetch('https://api.openai.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${process.env.OPENAI_API_KEY}`,
    },
    body: JSON.stringify({
      model: 'gpt-4o-mini',
      messages: [{ role: 'user', content: String(req.body?.message || '').slice(0, 2000) }],
    }),
  });

  const data = await r.json();
  res.status(r.status).json({ reply: data.choices?.[0]?.message?.content ?? '' });
}

وفي الفرونت إند من غير أي مفتاح:

const r = await fetch('/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ message: 'أهلًا' }),
});
const { reply } = await r.json();

وبعدين في Vercel: Settings ← Environment Variables ← ضيف OPENAI_API_KEY (من غير NEXT_PUBLIC_ ولا VITE_).

💡 نفس الفكرة موجودة ببلاش في Netlify Functions وCloudflare Workers. ولو بتستخدم مزوّد تاني (Claude أو Gemini)، غيّر الرابط والـheaders حسب الدوكس بتاعته.

🛡️ زيادة أمان: حط حد لطول الرسالة (زي .slice(0, 2000) فوق)، وفكّر في rate limit لو الموقع عليه زيارات كتير.

٣) حط ليميت على الحساب 🛑

في لوحة التحكم بتاعة مزوّد الـAI (OpenAI أو Anthropic أو غيرهم) هتلاقي Limits أو Budget أو Usage:

  • حط حد شهري (مثلًا $10).
  • شغّل تنبيه بالإيميل لما توصل لنسبة منه.
  • لو المزوّد بيسمح، اعمل مفتاح لكل مشروع، علشان لو واحد اتسرق مايأثرش على الباقي.

✅ تشيك ليست قبل ما ترفع أي موقع

  • [ ] مفيش sk- أو أي مفتاح في كود الفرونت إند.
  • [ ] مفيش مفاتيح في متغيرات بتبدأ بـVITE_ / NEXT_PUBLIC_ / REACT_APP_.
  • [ ] .env موجود في .gitignore.
  • [ ] الـAPI بيتنادى من Serverless Function مش من المتصفح.
  • [ ] فيه ليميت شهري وتنبيه على الحساب.
