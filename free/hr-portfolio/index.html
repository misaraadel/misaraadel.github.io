١) إنت مين… في سطر واحد، فوق خالص ⬆️

أول سطر في الصفحة لازم يقول بتعمل إيه + دليل.

❌ «أهلًا 👋 أنا مطوّر شغوف بحب البرمجة»

✅ أمثلة تقدر تعدّل عليها:

  • «Front-End Developer · React · عملت ٣ مواقع لعملاء حقيقيين»
  • «Junior Full-Stack · Node.js وReact · بنيت سيستم حجز بيستخدمه ٥٠٠ مستخدم»
  • «Front-End · Vue · خلّيت متجر يفتح في أقل من ثانية (Lighthouse 97)»

💡 لو معندكش عملاء لسه، استخدم رقم من مشروع: سرعة، عدد مستخدمين، أو حاجة اتحلّت.

٢) ٣ مشاريع بس 🗂️

كل مشروع فيه:

  • صورة للمشروع نفسه (مش أيقونة).
  • لينك Live شغّال (ولينك GitHub تحته).
  • سطر: حلّ مشكلة إيه؟ مش «عملت todo app بـReact».

❌ ٢٠ مشروع todo وcalculator وclone.

✅ ٣ مشاريع شبه شغل حقيقي: موقع لمحل، سيستم حجز، داشبورد.

٣) زرار تواصل واضح + CV بدوسة واحدة 📩

  • زرار «كلّمني» ظاهر من غير سكرول (إيميل أو LinkedIn أو واتساب).
  • زرار «📄 CV» بيفتح PDF على طول. مش «ابعتلي وهبعتهولك».

البرومبت 🎁

انسخه، وبدّل اللي بين [ ]، والصقه في ChatGPT أو Claude:

Build me a personal portfolio website in a single index.html file (HTML + CSS + JS, no frameworks, Google Fonts allowed).

The visitor is a recruiter who will decide in 6 seconds. Above the fold, without scrolling, they must see:
1. One line: who I am + proof. Use exactly: "[e.g. Front-End Developer · React · Built 3 sites for real clients]"
2. Two buttons: "Contact me" ([email or LinkedIn link]) and "Download CV" (links to cv.pdf, opens directly).
3. The start of my projects section.

About me:
- Name: [Your Name]
- Photo: me.jpg
- Skills (max 6): [e.g. HTML, CSS, JavaScript, React, Tailwind, Git]

Projects (exactly 3), each card has: a screenshot (use [project1.jpg]), the title, ONE line on the problem it solved, a "Live" button and a "GitHub" link:
- [Project 1 name] – [problem it solved] – [live link] – [github link]
- [Project 2 name] – [problem it solved] – [live link] – [github link]
- [Project 3 name] – [problem it solved] – [live link] – [github link]

Do NOT use: "passionate developer", "Hi 👋 I'm", long bios, skill progress bars, more than 3 projects, purple gradients.

Design: dark theme, one accent color ([#22c55e]), big clear typography, lots of spacing, subtle fade-in on scroll, fully responsive (mobile first).
Footer: © current year, and this exact credit line: "Template by @misarahamed.webdeveloper" linking to https://www.instagram.com/misarahamed.webdeveloper/ (opens in a new tab).
Give me the complete file in one code block.
