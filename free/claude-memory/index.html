١) CLAUDE.md: ذاكرة المشروع 📄

ملف بيقراه Claude لوحده في أول كل محادثة.

اعمله بأمر واحد جوه فولدر المشروع:

/init

Claude هيقرا المشروع ويكتبلك الملف. بعد كده زوّد عليه قواعدك.

قالب تنسخه:

# [اسم المشروع]: [بيعمل إيه في سطر]

## التقنيات
- [Next.js 15 / React / Tailwind / ...]

## الأوامر
- التشغيل: npm run dev
- التستات: npm test
- البيلد: npm run build

## القواعد
- الألوان: [لون أساسي] و[لون تاني] بس. ممنوع ألوان من برّه الثيم.
- الكومبوننتس في components/ وكل واحد في ملف لوحده.
- متعدّلش في [فولدر حساس] من غير ما تسألني.
- بعد أي تعديل شغّل التستات وقولي النتيجة.

💡 لو لقيت نفسك بتقوله نفس الملاحظة مرتين، حطها في الملف.

٢) Context7: دوكس جديدة 📗

Claude ممكن يكتب كود بطريقة قديمة لأن معلوماته متوقفة عند تاريخ معيّن. Context7 بيجيبله الدوكيومنتيشن الجديدة لأي مكتبة.

التسطيب (محتاج Node.js 22.13 أو أحدث):

npx ctx7 setup --claude

وبعدين في البرومبت قول: «use context7» أو «استخدم context7 للدوكس».

📂 github.com/upstash/context7

٣) Plan Mode: يخطط الأول 📋

دوس Shift + Tab لحد ما تشوف تحت ⏸ plan mode on.

في الوضع ده Claude بيقرا ويخطط من غير ما يعدّل أي ملف، ويعرض عليك الخطة. لو موافق، يبدأ ينفذ.

💡 استخدمه قبل أي تعديل كبير، أو لما مش متأكد Claude فاهم إنت عايز إيه.

٤) /compact: لما الشات يطوّل 📝

/compact

بيلخّص المحادثة ويكمّل من الملخص، فمبيتقلش ومبينساش اللي اتعمل.

وتقدر تقوله يركّز على إيه:

/compact ركّز على اللي اتعمل في صفحة الدفع والحاجات اللي فاضلة

💡 لو هتبدأ حاجة مختلفة خالص، /clear أحسن: يبدأ صفحة جديدة.

٥) سكيل بتاعتك ✍️

الحاجة اللي بتشرحهاله كل مرة (إزاي ترفع الموقع، إزاي تكتب تست، شكل الكومنتات…) اكتبها مرة واحدة في ملف.

المكان: .claude/skills/deploy/SKILL.md جوه المشروع (أو ~/.claude/skills/ لكل مشاريعك).

---
name: deploy
description: استخدمها لما أقولك ارفع الموقع أو اعمل deploy.
---

1. شغّل التستات الأول، ولو فيه حاجة فشلت وقّف وقولّي.
2. اعمل npm run build.
3. ارفع على Vercel وابعتلي اللينك.

بعد كده كفاية تقوله «ارفع الموقع» 🚀

✅ الترتيب

/init في أول المشروع ← Context7 مرة واحدة ← Plan Mode قبل أي تعديل كبير ← /compact لما الشات يطوّل ← سكيل لكل حاجة بتكررها.
