الريبو 📦

github.com/magicuidesign/magicui

  • أكتر من 23 ألف نجمة على GitHub، ورخصة MIT، يعني تستخدمه ببلاش في أي مشروع حتى لو تجاري.
  • أكتر من 150 كومبوننت متحركين: زراير بتنوّر، وخلفيات بتتحرك، وكروت، وكرة أرضية ثري دي، وأرقام بتعدّ لوحدها.
  • مبني بـReact وTypeScript وTailwind CSS وMotion، وشغال مع shadcn/ui.

تتفرج على الكومبوننتس منين؟ 👀

magicui.design/docs/components

  • كل كومبوننت ليه صفحة فيها Preview تشوفه شغال، وCode تنسخه.

تحطه في مشروعك إزاي؟ 🛠️

  1. لازم يكون عندك مشروع Next.js أو React + Vite فيه Tailwind.
  2. لو لسه مستخدمتش shadcn قبل كده، شغّل الأمر ده مرة واحدة:
npx shadcn@latest init
  1. اختار الكومبوننت اللي عاجبك، وانسخ أمر التسطيب من صفحته. مثلًا الزرار اللي بينوّر:
npx shadcn@latest add @magicui/rainbow-button
  1. استخدمه في الصفحة:
import { RainbowButton } from "@/components/ui/rainbow-button";

export default function Hero() {
  return <RainbowButton>Get Started</RainbowButton>;
}

٥ كومبوننتس تبدأ بيهم 🔥

  • rainbow-button: زرار بنور ألوان تحته، للـCTA الأساسي.
  • retro-grid: خلفية شبكة بتتحرك ورا الـHero.
  • number-ticker: أرقام بتعدّ، للإحصائيات («+50 مشروع»).
  • globe: كرة أرضية ثري دي بتلف.
  • marquee: شريط لوجوهات أو آراء عملاء بيتحرك لوحده.
