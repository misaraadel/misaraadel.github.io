💻 أول مشهد 3D (١٠ دقايق)

  1. اعمل ملف اسمه index.html وحط فيه الكود ده.
  2. افتحه بـ Live Server في VS Code. ماينفعش تدبل كليك عليه، لإن الـmodules محتاجة سيرفر.
  3. هتلاقي مكعب بيلف، وتقدر تلفّه بالماوس 🎉
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <title>My first 3D scene</title>
  <style>body { margin: 0; overflow: hidden; background: #050816; }</style>
  <script type="importmap">
  {
    "imports": {
      "three": "https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js",
      "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.170.0/examples/jsm/"
    }
  }
  </script>
</head>
<body>
<script type="module">
  import * as THREE from 'three';
  import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

  // 1) المشهد + الكاميرا + الرسام
  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 100);
  camera.position.set(0, 1.5, 4);
  const renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setSize(innerWidth, innerHeight);
  renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
  document.body.appendChild(renderer.domElement);

  // 2) مكعب
  const cube = new THREE.Mesh(
    new THREE.BoxGeometry(1.5, 1.5, 1.5),
    new THREE.MeshStandardMaterial({ color: '#38bdf8', roughness: 0.3, metalness: 0.4 })
  );
  scene.add(cube);

  // 3) إضاءة
  scene.add(new THREE.AmbientLight('#ffffff', 0.4));
  const light = new THREE.DirectionalLight('#ffffff', 2);
  light.position.set(3, 4, 5);
  scene.add(light);

  // 4) تحكم بالماوس
  const controls = new OrbitControls(camera, renderer.domElement);
  controls.enableDamping = true;

  // 5) الأنيميشن
  const clock = new THREE.Clock();
  renderer.setAnimationLoop(() => {
    const t = clock.getElapsedTime();
    cube.rotation.x = t * 0.5;
    cube.rotation.y = t * 0.8;
    controls.update();
    renderer.render(scene, camera);
  });

  // 6) لو الشاشة اتغيّر حجمها
  addEventListener('resize', () => {
    camera.aspect = innerWidth / innerHeight;
    camera.updateProjectionMatrix();
    renderer.setSize(innerWidth, innerHeight);
  });
</script>
</body>
</html>

### جرّب تعدّل 🧪

  • بدّل BoxGeometry بـ TorusKnotGeometry(1, 0.35, 128, 32) وشوف هيحصل إيه.
  • غيّر اللون #38bdf8 لأي لون تحبه.
  • خلّي السرعة t * 2 بدل t * 0.8.

⚛️ لو بتشتغل React (React Three Fiber)

npm install three @react-three/fiber @react-three/drei
import { Canvas, useFrame } from '@react-three/fiber';
import { OrbitControls } from '@react-three/drei';
import { useRef } from 'react';

function Box() {
  const ref = useRef();
  useFrame((_, dt) => { ref.current.rotation.x += dt * 0.5; ref.current.rotation.y += dt * 0.8; });
  return (
    <mesh ref={ref}>
      <boxGeometry args={[1.5, 1.5, 1.5]} />
      <meshStandardMaterial color="#38bdf8" roughness={0.3} metalness={0.4} />
    </mesh>
  );
}

export default function Scene() {
  return (
    <Canvas camera={{ position: [0, 1.5, 4] }} style={{ height: '100vh' }}>
      <ambientLight intensity={0.4} />
      <directionalLight position={[3, 4, 5]} intensity={2} />
      <Box />
      <OrbitControls enableDamping />
    </Canvas>
  );
}

🤖 برومبت تدّيه للـAI علشان يعملك Hero 3D

عايز Hero section لموقعي فيها مشهد 3D بـ Three.js (أو React Three Fiber لو المشروع React):
- شكل 3D واحد بسيط (مثلاً TorusKnot أو كورة) بيلف ببطء ويتحرك شوية مع حركة الماوس.
- إضاءة حلوة وخلفية غامقة، والعنوان والزرار فوق المشهد.
- خلّي الـpixelRatio بحد أقصى 2، ووقّف الأنيميشن لما التاب يبقى مش ظاهر.
- على الموبايل خلّي المشهد أخف (عدد polygons أقل) أو اعرض صورة بداله لو الجهاز ضعيف.
- اكتب الكود كامل في ملف واحد واشرحلي كل جزء في سطر.

⚠️ ٣ حاجات قبل ما تحط 3D في موقع حقيقي

  • السرعة أهم من الشكل: صغّر الموديلات (glTF + Draco)، والصور بصيغة WebP/KTX2.
  • الموبايل: جرّب الموقع على موبايل متوسط مش على الآيفون بتاعك بس.
  • ماتخليش الـ3D يخبّي المحتوى: الزبون جاي يعرف إنت بتعمل إيه، مش جاي يستنى Loading ٢٠ ثانية.
