الباكدج دي من GitHub وشركاها، وبتدّي الطلاب أدوات المطورين بيدفعوا فيها فلوس، ببلاش.

الصفحة الرسمية: education.github.com/pack

العروض دي منقولة من الصفحة الرسمية يوم 19 نوفمبر 2026، والعروض بتتغير، فاتأكد منها هناك قبل ما تقدّم.

أهم العروض

  • 🌐 دومين .me سنة ببلاش: من Namecheap، ومعاه شهادة SSL سنة.
  • 🌐 دومين .tech سنة ببلاش: من .TECH.
  • 🤖 GitHub Copilot Student: للطلاب المتأكَّد منهم.
  • 💻 JetBrains: اشتراك مجاني للطلاب (IntelliJ IDEA، وPyCharm، وغيرهم)، وبيتجدد كل سنة.
  • 📚 Frontend Masters: ٦ شهور ببلاش لكل الكورسات والورش.
  • ☁️ Heroku: 13 دولار كريديت كل شهر لمدة 24 شهر، تستضيف عليهم مشاريعك.
  • ☁️ Microsoft Azure: 100 دولار كريديت + خدمات مجانية، للي عنده 18 سنة أو أكتر.
  • 📘 Educative: ٦ شهور ببلاش. Scrimba: شهر Pro ببلاش.

إزاي تقدّم

  1. ادخل على education.github.com/pack ودوس Sign up for Student Developer Pack.
  2. سجّل دخول بحساب GitHub بتاعك.
  3. اختار إنك Student، واكتب اسم جامعتك.
  4. اتأكد من نفسك بـإيميل الجامعة، أو ارفع صورة كارنيه الكلية أو أي ورقة رسمية فيها تاريخ النهارده.
  5. استنى المراجعة. ولما يوافقوا، العروض بتظهرلك في صفحة الباكدج، وكل عرض فيه زرار تفعّله منه.

نصايح

  • اكتب بياناتك زي ما هي في الكارنيه بالظبط، علشان الطلب مايترفضش.
  • فعّل الدومين الأول، واربطه بالبورتفوليو بتاعك على GitHub Pages. شوف صفحة البورتفوليو.
  • لو لسه مش طالب أو اتخرجت: فيه دومين ببلاش برضو، بس subdomain. شوف الدومين المجاني.
