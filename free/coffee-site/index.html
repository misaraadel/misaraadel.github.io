الموقع شغّال 🔗

misaraadel.github.io/demo/coffee

  • افتحه من الموبايل واعمل سكرول بالراحة: الفنجان بيلف، والبُن بيقع ولونه بيتحمّص من أخضر لغامق، وكروت المنيو بتتقلب.
  • البراند «بُنّ البلد» متألف، وده موقع تجريبي علشان تتعلم منه.

الكود كامل 💻

github.com/misaraadel/misaraadel.github.io/blob/master/demo/coffee/index.html

  • ملف واحد بس: HTML وCSS وJavaScript، من غير أي framework.
  • الأنيميشن معمول بمكتبة GSAP وScrollTrigger (ببلاش).
  • الفناجين والبُن مرسومين بـSVG جوه الكود، يعني مفيش ولا صورة تحمّلها.

إيه اللي بيخلّي الموقع «شكله غالي»؟ ✨

  1. ألوان قليلة ومتناسقة: كريمي فاتح، وبني غامق، ولون كراميل للأزرار. ولو عايز تختار ألوانك، استخدم coolors.co.
  2. خطّين بس: واحد للعناوين (El Messiri) وواحد للكلام (Tajawal)، الاتنين من Google Fonts.
  3. أنيميشن ليه معنى: البُن بيتحمّص وإنت بتعمل سكرول، يعني الحركة بتحكي قصة البراند، مش حركة وخلاص.
  4. تفاصيل صغيرة: ظل ناعم، وزرار بيلمع لما تعدّي عليه، وكروت بتتقلب، وأرقام بتعدّ.
  5. زرار واضح يجيب فلوس: «اطلب على الواتساب» بيفتح رسالة جاهزة على طول.
  6. احترام المستخدم: لو حد مفعّل «تقليل الحركة» في موبايله، الأنيميشن بيقف (prefers-reduced-motion).

تعدّل الموقع لبراندك إزاي؟ 🛠️

  1. نزّل ملف index.html من لينك الكود.
  2. غيّر الاسم والكلام والأسعار.
  3. غيّر الألوان من أول الـCSS (:root).
  4. في زرار الواتساب، حط رقمك كده: https://wa.me/20XXXXXXXXXX?text=...
  5. ارفعه على GitHub Pages ببلاش.

🤖 برومبت تعمل بيه موقع زيه لأي براند

Build a premium one-page landing site for my brand in a single index.html file (HTML + CSS + vanilla JS).
Brand: [name] — [what it sells] in [city]. Language: [Arabic RTL / English]. Audience: [who].

Style:
- A small palette (one light background, one dark, one accent) defined as CSS variables.
- Two Google Fonts: one display font for headings, one clean font for body text.
- Soft shadows, rounded cards, lots of white space. Must look expensive, not template-like.

Sections:
1. Hero: big headline + short line + primary CTA, with a hero visual drawn in inline SVG that animates in.
2. A pinned storytelling section with GSAP ScrollTrigger (scrub) that tells how we make our product in 3 steps,
   with one visual that transforms while scrolling (like coffee beans roasting from green to dark).
3. Products as 3D flip cards (front: visual + name + price, back: description + options + button).
4. Stats with count-up numbers.
5. Reviews in an auto-scrolling marquee.
6. Final CTA with a WhatsApp order button (https://wa.me/[number]?text=[prefilled message]).

Rules: load GSAP + ScrollTrigger from cdnjs, fully responsive (mobile first), respect prefers-reduced-motion,
no external images (draw visuals with SVG), and keep the code clean and commented.
