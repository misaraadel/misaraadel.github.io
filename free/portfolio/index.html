إزاي تستخدمه

  1. انسخ البرومبت اللي تحت، وبدّل كل حاجة بين [ ] ببياناتك.
  2. الصقه في ChatGPT أو Claude، وهيدّيك ملف index.html كامل.
  3. ارفع الملف مع صورتك باسم me.jpg على repository جديد في GitHub.
  4. Settings ← Pages ← اختار الـbranch ← Save، وبعد دقيقة موقعك يبقى على username.github.io.

البرومبت

Build me a personal portfolio website in a single index.html file (HTML + CSS + JavaScript all inside the same file, no frameworks, no external files except Google Fonts).

About me:
- Name: [Your Name]
- Job title: [e.g. Front-End Developer]
- Short bio: [2–3 lines about you]
- Skills: [e.g. HTML, CSS, JavaScript, Vue 3, Tailwind CSS]
- Projects (3): [Project name – short description – live link] ×3
- Contact: GitHub [link], LinkedIn [link], WhatsApp [number], Email [email]
- Photo: use "me.jpg" (I'll upload it next to index.html)

Sections:
1. Navbar with my name and links to each section
2. Hero: my photo, name, job title, one strong line about what I do, and a "Contact me" button
3. About: short bio + skills as tags/chips
4. Projects: 3 cards, each with an image placeholder, title, description, and a "View live" button
5. Contact: buttons for GitHub, LinkedIn, WhatsApp, and Email
6. Footer with © and the current year, plus this exact credit line under it:
   "Template by @misarahamed.webdeveloper" linking to https://www.instagram.com/misarahamed.webdeveloper/ (opens in a new tab)
7. A floating WhatsApp button in the corner

Design:
- Modern dark theme with one accent color (green #22c55e)
- Clean typography, rounded cards, soft shadows, plenty of spacing
- Smooth fade-in animation on scroll and hover effects on buttons and cards
- Fully responsive (looks great on mobile first)
- Good SEO basics: title, meta description, and Open Graph tags

Give me the complete file in one code block, ready to upload to GitHub Pages.
