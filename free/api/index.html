كل الـAPIs دي موجودة في الريبو public-apis على GitHub (حوالي 500 ألف نجمة):

github.com/public-apis/public-apis

No key يعني تقدر تستخدمه على طول. API key يعني محتاج تعمل حساب ببلاش وتاخد key، وما ترفعهوش على GitHub.

افتح الـdocs بتاعة كل API قبل ما تبدأ، علشان الشروط والحدود ممكن تتغير.

الأفكار

  1. 🌦️ تطبيق طقس لايف: المدينة، والحرارة، والأيام الجاية. الـAPI: Open-Meteo (No key).
  2. 💱 محوّل عملات: جنيه/دولار/يورو، مع رسم بياني لآخر شهر. الـAPI: Frankfurter (No key).
  3. 📖 آية اليوم + فهرس السور: بحث في السور، وتشغيل التلاوة. الـAPI: Quran Cloud (No key).
  4. 📚 قاموس إنجليزي: المعنى، والنطق، والأمثلة. الـAPI: Free Dictionary (No key).
  5. 📕 مكتبة كتب: بحث بالاسم، وصور الأغلفة، وليستة «عايز أقراه». الـAPI: Open Library (No key).
  6. 🐉 Pokédex: كروت، وفلتر بالنوع، وصفحة لكل بوكيمون. الـAPI: PokéAPI (No key).
  7. 😂 مولّد نكت: فلتر بالنوع، وزرار «نكتة تانية»، ومشاركة. الـAPI: JokeAPI (No key).
  8. 🗓️ الإجازات الرسمية: اختار الدولة والسنة، وعدّاد للإجازة الجاية. الـAPI: Nager.Date (No key).
  9. 🎬 موقع أفلام: الأكتر مشاهدة، وبحث، وصفحة لكل فيلم، وقايمة مفضلة. الـAPI: TMDb (API key).
  10. ⚽ نتايج الكورة: ماتشات النهارده، والترتيب، والهدافين. الـAPI: API-FOOTBALL (API key).

بونص: 🍝 موقع وصفات أكل بالمكونات. الـAPI: TheMealDB (API key).

علشان المشروع يفرق في البورتفوليو

  • ارفعه أونلاين على GitHub Pages وحط اللينك. (شوف ريل البورتفوليو وريل الدومين على صفحتي.)
  • زوّد حاجة من عندك: dark mode، أو حفظ في localStorage، أو فلاتر، أو تصميم موبايل محترم.
  • README واضح: صورة للمشروع، والـAPI اللي استخدمته، وإزاي تشغّله.
