is-a.dev مشروع مفتوح المصدر على GitHub (is-a-dev/register)، عليه حوالي 12 ألف نجمة، وبيدّي المطورين subdomain مجاني لمواقعهم الشخصية.

المصدر الرسمي للخطوات دي: docs.is-a.dev/guides/github-pages

قبل ما تبدأ

  • لازم يبقى عندك موقع شغال على GitHub Pages (username.github.io). لو معندكش، شوف ريل «بورتفوليو أونلاين في ٣ دقايق» على صفحتي.
  • اقرا الـTerms of Service بتاعتهم في الريبو.

الخطوات

  1. Fork: ادخل على github.com/is-a-dev/register ودوس Fork.
  2. ملف باسمك: في الفورك بتاعك افتح فولدر domains ← Add file ← Create new file. سمّي الملف yourname.json (مكان yourname الاسم اللي عايزه، يعني الدومين هيبقى yourname.is-a.dev).
  3. حط فيه ده (غيّر github-username بيوزرك على GitHub):
{
    "owner": {
        "username": "github-username"
    },
    "records": {
        "CNAME": "github-username.github.io"
    }
}
  1. Pull Request: دوس Commit changes، وبعدين Contribute ← Open pull request. املا الـtemplate بنفسك.
  2. استنى المراجعة. الطلب بيتراجع من فريقهم، ولو طلبوا تعديلات اعملها، علشان لو ما عملتهاش الطلب بيترفض.
  3. بعد الـMerge (مش قبله): ادخل على ريبو موقعك ← Settings ← Pages ← Custom domain، واكتب yourname.is-a.dev ← Save، وعلّم Enforce HTTPS.
  4. استنى شوية، وموقعك يشتغل على الدومين الجديد. ولو ظهرلك 404 في الأول، استنى وجرّب تاني.

⚠️ مهم

  • اكتب الطلب بنفسك. هما كاتبين في الريبو إن الـAI بيغلط في الطلب ده وهيأخّرك.
  • ما تحطش الدومين في Settings قبل ما الـPR يتعمله Merge.
