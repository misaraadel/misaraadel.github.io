سؤال إنترفيو: Debounce في ٥ سطور ⏱

من ريل «سيرش بار واحد… وقّع السيرفر» على إنستجرام:

المشكلة 💥

  • كل حرف اليوزر بيكتبه في السيرش بيبعت Request للسيرفر.
  • كلمة iphone لوحدها = ٦ Requests. ولو عندك مليون يوزر بيكتبوا مع بعض، يبقى ٦ مليون Request والسيرفر يقع.

الحل: Debounce ✅

  • بدل ما تبعت مع كل حرف، استنّى لحد ما اليوزر يبطّل كتابة ٣٠٠ مللي ثانية.
  • كل حرف جديد بيصفّر العدّاد (clearTimeout).
  • لما اليوزر يقف، العدّاد يخلص (setTimeout) وتبعت Request واحد بس.

الكود: ٥ سطور JavaScript

let timer;
input.addEventListener('input', (e) => {
  clearTimeout(timer);
  timer = setTimeout(() => search(e.target.value), 300);
});

نسخة تقدر تستخدمها في أي حتة

function debounce(fn, ms = 300) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}

// الاستخدام
const onSearch = debounce((q) => fetch(`/api/search?q=${q}`), 300);
input.addEventListener('input', (e) => onSearch(e.target.value));

في React ⚛️

import { useEffect, useState } from 'react';

function useDebounce(value, ms = 300) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), ms);
    return () => clearTimeout(id); // كل حرف جديد يلغي اللي قبله
  }, [value, ms]);
  return debounced;
}

// جوه الكومبوننت
const [query, setQuery] = useState('');
const q = useDebounce(query, 300);
useEffect(() => { if (q) fetch(`/api/search?q=${q}`); }, [q]);

🎯 ٣ أسئلة إنترفيو زيّه (بإجاباتها)

١ · إيه الفرق بين Debounce وThrottle؟

  • Debounce: بيستنّى لحد ما الحدث يقف، وبعدين ينفّذ مرة واحدة. مناسب للسيرش وفورم الـvalidation.
  • Throttle: بينفّذ مرة كل فترة ثابتة مهما الحدث اتكرر، مثلًا مرة كل ٢٠٠ مللي ثانية. مناسب للـscroll والـresize.
  • مثال تقوله: «الـscroll بيحصل ١٠٠ مرة في الثانية، بالـThrottle بنفّذ ٥ مرات بس.»

٢ · صفحة فيها ١٠٠ صورة… إزاي تخليها تفتح بسرعة؟

  • Lazy Loading: الصور اللي تحت متتحمّلش غير لما اليوزر يقرب منها.
  • أسهل طريقة سطر واحد في HTML:
<img src="photo.jpg" loading="lazy" alt="..." width="400" height="300">
  • حط width وheight علشان الصفحة متتنططش وهي بتحمّل (CLS).
  • للحاجات المتقدمة: IntersectionObserver.

٣ · ليستة فيها ١٠٠٠ عنصر… تحط ١٠٠٠ Event Listener؟

  • لأ. استخدم Event Delegation: Listener واحد على الأب، وتعرف مين اتداس عليه من e.target.
list.addEventListener('click', (e) => {
  const item = e.target.closest('li');
  if (item) console.log('clicked', item.dataset.id);
});
  • ميزة كمان: العناصر الجديدة اللي بتتضاف بعدين بتشتغل تلقائي.
