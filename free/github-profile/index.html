الخطوات

  1. على GitHub دوس New repository.
  2. سمّي الريبو بنفس اسم اليوزر بتاعك بالظبط. مثلًا لو اليوزر ahmed-dev، يبقى الريبو ahmed-dev. GitHub هيكتبلك إنه ريبو مميز.
  3. خليه Public، وعلّم على Add a README file، ودوس Create repository.
  4. افتح README.md ← ✏️ Edit، والصق اللي الـAI هيكتبهولك، ودوس Commit changes.
  5. افتح بروفايلك، هتلاقي الـREADME ظاهر أول حاجة.

البرومبت

Write a professional GitHub profile README.md for me in Markdown.

About me:
- Name: [your name]
- Role: [e.g. Front-End Developer]
- One-line intro: [what you build / what you're looking for]
- Currently working on / learning: [..]
- Skills: [e.g. HTML, CSS, JavaScript, Vue, Nuxt, Tailwind, Git]
- Top projects (3): [name — one line — live link — repo link] ×3
- Contact: [LinkedIn link], [portfolio link] (do NOT include my email or phone)

Include:
1. A centered header: "Hi 👋, I'm [name]" + role.
2. "About Me" as short bullet points with emojis.
3. "Tech Stack" as skill icons using https://skillicons.dev (one line of icons).
4. "Projects" as a small table: name, description, links.
5. "Connect with me" badges for LinkedIn and portfolio using shields.io.
6. A GitHub stats card at the end.
Keep it clean, short and easy to scan. Give me only the Markdown in one code block.
