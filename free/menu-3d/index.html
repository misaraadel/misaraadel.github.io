افتحه من الموبايل أو الكمبيوتر واعمل سكرول: كل ما تنزل، الأكلة بتلف وتتبدّل بالأكلة اللي بعدها (كشري ← فطير ← حواوشي ← فول).

الموقع ده HTML وCSS وJavaScript بس، من غير أي مكتبة. كل الحركة سببها CSS 3D transforms ومعاها سطرين JavaScript بيحسبوا الإنت نزلت قد إيه.

💡 الفكرة في ٣ خطوات

  1. قسم طويل وجواه حاجة sticky: القسم طوله 520vh، وجواه شاشة position: sticky واقفة مكانها وإنت بتعمل سكرول.
  2. بنحسب الإنت نزلت قد إيه (رقم من 0 لـ1):
const p = (scrollY - track.offsetTop) / (track.offsetHeight - innerHeight);
  1. الرقم ده بيحرّك كل حاجة: الطبق بيلف بـrotateZ ومايل بـrotateX علشان يبان 3D، وبين كل طبقين الطبق القديم بيطلع لفوق ويختفي والجديد بيدخل من تحت.

💻 الكود الأساسي (ملف واحد)

حط صور الأكل في فولدر img (يفضّل PNG أو WebP من غير خلفية) وغيّر الأسماء:

<!doctype html>
<html lang="ar" dir="rtl">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>منيو 3D</title>
<style>
  body { margin: 0; background: #120c08; color: #f6eadb; font-family: system-ui, sans-serif; }
  #track { height: 500vh; }
  #stage { position: sticky; top: 0; height: 100vh; overflow: hidden; }
  #wrap { position: absolute; left: 50%; top: 55%; width: min(80vw, 70vh); aspect-ratio: 1; transform: translate(-50%, -50%); perspective: 1400px; }
  .dish { position: absolute; inset: 0; }
  .dish img { width: 100%; height: 100%; object-fit: contain; filter: drop-shadow(0 40px 40px rgba(0,0,0,.6)); }
  #name { position: absolute; top: 12vh; width: 100%; text-align: center; font-size: 56px; font-weight: 800; }
</style>
</head>
<body>
<div id="track"><div id="stage"><div id="name"></div><div id="wrap"></div></div></div>
<script>
  const DISHES = [
    { img: 'img/koshari.webp', name: 'كشري' },
    { img: 'img/feteer.webp',  name: 'فطير مشلتت' },
    { img: 'img/hawawshi.webp', name: 'حواوشي' },
    { img: 'img/ful.webp',     name: 'طبق فول' },
  ];
  const wrap = document.getElementById('wrap'), nameEl = document.getElementById('name');
  const els = DISHES.map(d => { const e = document.createElement('div'); e.className = 'dish'; e.innerHTML = `<img src="${d.img}" alt="${d.name}">`; wrap.appendChild(e); return e; });
  const clamp = (v) => Math.min(1, Math.max(0, v));
  const ease = (k) => k < .5 ? 4*k*k*k : 1 - Math.pow(-2*k + 2, 3) / 2;

  function render() {
    const track = document.getElementById('track');
    const p = clamp((scrollY - track.offsetTop) / (track.offsetHeight - innerHeight));
    const x = p * (DISHES.length - 1), i = Math.min(DISHES.length - 1, Math.floor(x));
    const swap = ease(clamp((x - i - .45) / .55));       // الطبق ثابت نص الوقت، وبعدين يتبدّل
    const spin = x * 140;                                 // الطبق بيلف مع السكرول
    els.forEach((e, k) => {
      let o = 0, y = 0, s = 1, rz = spin, rx = 48;
      if (k === i)     { o = 1 - swap; y = -swap * 55; s = 1 - swap * .35; rz += swap * 90; }
      if (k === i + 1) { o = swap; y = (1 - swap) * 60; s = .65 + swap * .35; rz -= (1 - swap) * 120; }
      e.style.opacity = o;
      e.style.transform = `translateY(${y}%) rotateX(${rx}deg) rotateZ(${rz}deg) scale(${s})`;
    });
    nameEl.textContent = DISHES[swap > .5 ? Math.min(DISHES.length - 1, i + 1) : i].name;
    requestAnimationFrame(render);
  }
  render();
</script>
</body>
</html>

الكود الكامل بتاع الديمو (السعر، والوصف، والمؤشر، والبخار) موجود في الموقع نفسه: افتح الديمو ودوس Ctrl + U.

🖼️ صور الأكل من غير خلفية (ببلاش)

  • remove.bg أو Photoroom من الموبايل: ارفع الصورة وهتنزل من غير خلفية.
  • أحسن زاوية: صوّر الطبق من فوق (top-down)، علشان لما يلف يبان طبيعي.
  • صغّر الصورة لعرض ١٠٠٠ بيكسل تقريبًا، وحوّلها لـ WebP (من squoosh.app) علشان الموقع يفتح بسرعة.

🤖 برومبت تدّيه للـAI يعملك واحد لمطعمك

اعملي صفحة منيو لمطعم اسمه [اسم المطعم] بـ HTML وCSS وJavaScript بس في ملف واحد (من غير مكتبات):
- قسم طوله 500vh وجواه شاشة sticky.
- كل ما اليوزر يعمل سكرول، صورة الطبق (PNG من غير خلفية) تلف بـ rotateZ وتكون مايلة بـ rotateX(48deg) علشان تبان 3D.
- بين كل طبقين: الطبق القديم يطلع لفوق ويصغر ويختفي، والجديد يدخل من تحت وهو بيلف.
- جنب الطبق: اسم الأكلة بالعربي والإنجليزي، ووصف قصير، والسعر، وزرار "أضف للطلب".
- ألوان دافية (بني غامق ودهبي) وخط عربي حلو، ومؤشر تحت بيوضّح إحنا في أنهي طبق.
- على الموبايل: الكلام فوق والطبق في النص والسعر تحت.
- الأطباق: [كشري 45 ج.م، فطير 120 ج.م، ...]
اكتب الكود كامل واشرحلي كل جزء في سطر.
