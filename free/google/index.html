موقعك مش ظاهر في جوجل؟ 😶 صلّحه في ٣ خطوات

من ريل «موقعك مش ظاهر في جوجل» على إنستجرام:

👉 instagram.com/misarahamed.webdeveloper

لو الـAI عملّك الموقع بـReact (Vite)، الصفحة بتوصل لجوجل فاضية: <div id="root"></div> بس، والمحتوى كله بيتبني بالـJavaScript بعد ما الصفحة تفتح. جوجل ساعات بيستنى يشغّل الـJS، وساعات لأ، وغالبًا بيتأخر.

✅ اختبر موقعك دلوقتي (دقيقة واحدة)

  1. اكتب في جوجل: site:اسم-موقعك.com (من غير مسافة بعد site:).

لو مفيش نتايج ← جوجل مش شايف الموقع خالص.

  1. افتح موقعك ودوس Ctrl + U (أو Cmd + Option + U على الماك) علشان تفتح View Page Source.

لو لقيت <div id="root"></div> ومفيش أي كلام من موقعك ← جوجل بيشوفه ورقة بيضا.

  1. بص على اسم التاب: لو مكتوب Vite + React ← لسه ماغيّرتش الـtitle.

١) title و description لكل صفحة 🏷️

ده اللي بيظهر في نتيجة جوجل نفسها. افتح index.html وغيّر الـ<head>:

<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>متجر سارة | شنط وكروشيه هاند ميد</title>
  <meta name="description" content="شنط وكروشيه هاند ميد معمولة بحب، بتوصيل لكل مصر." />
  <link rel="canonical" href="https://your-site.com/" />
  <meta property="og:title" content="متجر سارة | هاند ميد" />
  <meta property="og:description" content="شنط وكروشيه هاند ميد بتوصيل لكل مصر." />
  <meta property="og:image" content="https://your-site.com/cover.jpg" />
</head>

💡 الـtitle أقل من ٦٠ حرف، والـdescription حوالي ١٥٠ حرف. ولو عندك أكتر من صفحة، كل صفحة ليها title مختلف (في React استخدم مكتبة زي react-helmet-async).

٢) sitemap.xml 🗺️

ملف بيقول لجوجل على كل صفحات موقعك. اعمل ملف public/sitemap.xml:

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://your-site.com/</loc></url>
  <url><loc>https://your-site.com/bags</loc></url>
  <url><loc>https://your-site.com/contact</loc></url>
</urlset>

واعمل ملف public/robots.txt:

User-agent: *
Allow: /
Sitemap: https://your-site.com/sitemap.xml

افتح your-site.com/sitemap.xml في المتصفح وتأكد إنه بيفتح.

٣) Google Search Console 🔍

  1. ادخل search.google.com/search-console وسجّل بحساب جوجل.
  2. Add property ← اختار URL prefix ← حط لينك موقعك.
  3. أثبت إنه موقعك: أسهل طريقة HTML tag. انسخ سطر الـ<meta name="google-site-verification" …> وحطه في الـ<head>، وارفع الموقع، ودوس Verify.
  4. من Sitemaps على الشمال ← اكتب sitemap.xml ← Submit.
  5. من URL Inspection فوق ← حط لينك الصفحة ← REQUEST INDEXING.

⏳ الظهور بياخد من كام يوم لأسبوعين تقريبًا. ماتطلبش indexing لنفس الصفحة كل شوية، مش هيسرّعها.

💯 ولو عايز تضمن: Next.js أو Astro

دول بيبعتوا الصفحة مليانة HTML من الأول (SSR / Static)، فجوجل بيشوف المحتوى على طول.

  • Astro: الأنسب لمواقع المحتوى، زي لاندينج أو بورتفوليو أو بلوج أو متجر صغير.
  • Next.js: لو الموقع فيه داشبورد أو تسجيل دخول أو حاجات كتير بتتغيّر.

البرومبت 🎁

انسخه، وبدّل اللي بين [ ]، والصقه في ChatGPT أو Claude أو Cursor:

Rebuild my website with [Astro / Next.js App Router] so every page is server-rendered or statically generated (the HTML must contain the full content, not an empty <div id="root">).

Site: [what the site is, e.g. a handmade bags store in Egypt]
Language: Arabic, dir="rtl"
Pages: [Home, Products, Product page, Contact]

SEO requirements:
1. A unique <title> (under 60 characters) and <meta name="description"> (around 150 characters) for EVERY page, written in Arabic for real customers.
2. Open Graph tags (og:title, og:description, og:image) and a canonical URL on every page.
3. Exactly one <h1> per page, then logical <h2>/<h3>.
4. Descriptive alt text on every image.
5. Generate sitemap.xml automatically from all pages, and add robots.txt that points to it.
6. Clean URLs like /products/crochet-bag (no #hash routing).
7. Fast: optimized images, no unnecessary JavaScript.

Keep my current design and content. Give me the full project structure and every file.

✅ تشيك ليست

  • [ ] اسم التاب مش «Vite + React».
  • [ ] كل صفحة ليها title وdescription مختلفين.
  • [ ] sitemap.xml وrobots.txt بيفتحوا.
  • [ ] الموقع متضاف في Search Console، والـsitemap متبعت.
  • [ ] طلبت indexing للصفحة الرئيسية.
  • [ ] View Page Source فيه كلام موقعك، مش div فاضي بس.
