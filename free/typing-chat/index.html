✅ الإجابة: B: ستين ألف

١٠٠٠ يوزر × ريكويست كل ثانية × ٦٠ ثانية = ٦٠,٠٠٠ ريكويست في الدقيقة، وأغلبها بيرجع «مفيش جديد».

Polling ❌ و WebSocket ✅

  • Polling: المتصفح بيخبّط على السيرفر كل ثانية: «فيه جديد؟». تقيل على السيرفر، وفيه تأخير.
  • WebSocket: خط واحد بيتفتح مرة واحدة ويفضل مفتوح. أول ما صاحبك يدوس حرف، السيرفر هو اللي بيبعتلك.

💻 الكود على GitHub

شات كامل بـ«بيكتب…» (Node.js + HTML)، ومعاه شرح عربي:

👉 github.com/misaraadel/misaraadel.github.io/tree/master/code/typing-chat

شغّله:

npm install
npm start

وافتح http://localhost:3000 في تابين.

🧠 في الإنترفيو قول كمان

  • WebSocket مش لكل حاجة: لو البيانات بتتغير كل كام دقيقة، الـpolling العادي كفاية.
  • لو السيرفر بس هو اللي بيبعت (نوتيفيكيشنز مثلًا)، فيه Server-Sent Events (SSE) وهي أبسط.
  • مكتبات زي Socket.IO بتعمل reconnect لوحدها لو النت فصل.
