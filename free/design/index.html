إزاي تستخدمه

  1. انسخ البرومبت اللي تحت كله.
  2. غيّر كل حاجة بين [ ] بتفاصيل موقعك.
  3. الصقه في ChatGPT أو Claude، وهيدّيك الموقع كامل في ملف index.html واحد.

التلات سطور اللي بتفرق

  • ١. هوية: لون، وخط، ومزاج. من غيرهم الـAI بيختار البنفسجي وخط Inter.
  • ٢. ممنوعات بالاسم: إنت بتقوله بالظبط إيه الحاجات المكررة اللي مايستخدمهاش.
  • ٣. فكرة واحدة جريئة: حاجة واحدة تخلّي الموقع يتفتكر.

البرومبت

Build a landing page for [product name: what it does, who it's for] in a single index.html file (HTML + CSS + JS).

1) Identity. Use exactly this:
- Colors: [background color], [text color], and ONE accent color: [accent]. No other colors.
- Fonts (Google Fonts): [display font] for headings, [body font] for text.
- Mood: [3 words, e.g. calm, witty, editorial].

2) Do NOT use any of these:
purple or blue gradients, gradient text, the Inter font, emojis as icons, "Powered by AI" badges,
a centered hero with two buttons, a row of 3 feature cards with icons, glassmorphism,
and phrases like "Get Started", "Unlock your potential", "Supercharge", "Seamless", "Next-level".

3) One bold idea. Build the whole page around one memorable element that only fits this product,
for example: [a to-do list that crosses itself out / a price tag that changes as you scroll / ...].
If I didn't give you one, invent one and tell me what it is.

Also: an asymmetric layout, real specific copy (no filler), subtle animations, and fully responsive.
In the footer, add this exact credit line: "Design prompt by @misarahamed.webdeveloper" linking to https://www.instagram.com/misarahamed.webdeveloper/ (opens in a new tab).
Give me the complete file in one code block.
