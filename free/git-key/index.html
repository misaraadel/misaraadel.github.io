مسحت المفتاح من الكود؟ لسه مكشوف 🔒 الخطوات كاملة

من ريل «غلطات مواقع الـAI #٤: المفتاح المكشوف» على إنستجرام:

👉 instagram.com/misarahamed.webdeveloper

لما ترفع مفتاح (API key) على GitHub وبعدين تمسحه في commit جديد، المفتاح بيفضل موجود في الـhistory. أي حد يقدر يفتح الكوميتات القديمة ويلاقيه. وفيه بوتات بتدوّر في الريبوهات الـpublic على مفاتيح زي sk- وAKIA وghp_، وبتلاقيها في دقايق.

💡 الكلام ده على الريبو الـPublic. وحتى لو الريبو Private، اتعامل مع المفتاح على إنه اتسرّب لو حد تاني معاه access.

✅ اختبر الريبو بتاعك دلوقتي (دقيقتين)

  1. افتح أي فايل في الريبو على GitHub.
  2. في اللينك، غيّر github.com لـ github.githistory.xyz واتفرّج على كل نسخ الفايل.
  3. أو من التيرمنال جوه فولدر المشروع:
git log -p | grep -n -E "sk-|api_key|apiKey|SECRET|TOKEN"

لو طلعلك أي مفتاح حقيقي، كمّل الخطوات اللي تحت فورًا.

🚨 أول ٣ خطوات لو مفتاحك اتسرّب (بالترتيب ده)

  1. اعمل Revoke للمفتاح من حسابك عند الخدمة نفسها (OpenAI، Google، Stripe…)، واعمل واحد جديد. دي أهم خطوة. مسح المفتاح من الكود مش بيوقفه، لكن الـRevoke بيخلّيه ميشتغلش خالص.
  2. بُص على الفاتورة والـUsage في الحساب، وحط حد أقصى للصرف (Usage limit) علشان لو حصلت تاني ماتتفاجئش.
  3. حط المفتاح الجديد في .env مش في الكود (الخطوات تحت)، واتأكد إنه مش بيروح للمتصفح.

🧹 تمسحه من الـhistory صح (اختياري، بعد الـRevoke)

بعد ما تعمل Revoke، المفتاح القديم بقى ملوش لازمة. لكن لو عايز تنضّف الريبو:

بـ git-filter-repo:

pip install git-filter-repo
echo 'sk-proj-OLD_KEY_HERE==>REMOVED' > replace.txt
git filter-repo --replace-text replace.txt
git push --force --all
  • --force بيغيّر الـhistory، فلو فيه ناس تانية شغالة معاك على الريبو قولّهم يعملوا clone من جديد.
  • النسخ اللي حد عملها fork أو clone قبل كده مش هتتمسح. علشان كده الـRevoke هو الأساس.
  • بديل أسهل: BFG Repo-Cleaner.

🔐 .env و.gitignore صح

١) اعمل ملف .env في فولدر المشروع:

OPENAI_API_KEY=sk-proj-xxxxxxxx

٢) ضيف .env في .gitignore قبل أول commit:

.env
.env.*
!.env.example

٣) اعمل .env.example من غير القيم الحقيقية علشان اللي ياخد الريبو يعرف محتاج إيه:

OPENAI_API_KEY=

٤) اقرا المفتاح في الكود (Node.js):

import 'dotenv/config';
const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

٥) لو .env اترفع قبل كده:

git rm --cached .env
git commit -m "stop tracking .env"

وبعدها اعمل Revoke للمفتاح برضو، لإنه موجود في الـhistory.

⚠️ أي متغيّر بيبدأ بـVITE_ أو NEXT_PUBLIC_ أو REACT_APP_ بيتحط في كود المتصفح، يعني أي زائر يقدر يشوفه. مفاتيح الـAI لازم تفضل على السيرفر (Serverless Function مثلًا). الشرح كامل في هدية الـAPI Key بتاعك مكشوف.

🛡️ خلّي GitHub يحميك

  • Settings ← Code security ← Secret Protection / Push protection: GitHub بيمنعك ترفع commit فيه مفتاح معروف قبل ما يتنشر.
  • Dependabot / Secret scanning alerts: بيبعتلك تنبيه لو لقى مفتاح في الريبو.

🤖 برومبت تدّيه للـAI قبل ما ترفع أي مشروع

راجع المشروع ده قبل ما أرفعه على GitHub:
- طلّعلي أي API key أو password أو token مكتوب في الكود مباشرة.
- انقلهم لملف .env، واعمل .env.example، وضيف .env في .gitignore.
- اتأكد إن مفيش مفتاح سري بيوصل لكود المتصفح (VITE_ / NEXT_PUBLIC_ / REACT_APP_)، ولو فيه انقله لـ serverless function.
- اكتبلي الملفات اللي اتغيرت كاملة.
